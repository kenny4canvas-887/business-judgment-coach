# 《增长算力》经营判断陪练教练

一个约 15 分钟的经营判断练习 Skill。它先澄清你真正要判断的事，再用关键追问和新条件帮助你检验取舍，最后留下可回看的判断依据与修正过程。

## 怎么使用

- 不知道练什么：说“给我一个客户经营案例，陪我练 15 分钟”。
- 有真实难题但还说不清：描述现象，教练会先帮你找核心矛盾。
- 已经明确问题：直接说出要做的选择、依据和约束，教练会据此追问或复盘。

在支持 Skills 的环境中安装本仓库后，入口见 [SKILL.md](SKILL.md)。课堂案例见 [案例库](references/cases.md)，许可与素材边界见 [LICENSE.md](LICENSE.md)。案例均为教学练习；真实经营决策需要结合企业数据与人工判断。
