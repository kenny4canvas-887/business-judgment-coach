# 常见问题与处理（教练查阅）

- **“我不知道练什么。”** 给虚构案例和真实决定两个入口，请他选一个；选案例只给开场条件和一个选择问题。
- **“我说了很多，你怎么还不回答？”** 用他的话复述正在犹豫的两边，指出唯一还不清楚的取舍，请他选择或纠正；核心已清楚就推进，不继续盘问。
- **“直接告诉我怎么办。”** 已知目标、取舍和主要约束时，给条件式建议、缺失证据和停止条件；不伪装成学员自己得出的结论。
- **“我不想做图卡／文件存不下来。”** 用正文保留初判、触动的一问、当前判断、教练一句反馈和下一次检验；不声称已经生成文件。
- **“输入 JSON 损坏或路径错误。”** 生成器会区分路径不存在、权限不足和 JSON 格式错误；按提示检查 UTF-8 JSON 对象、非空必填字段或文件位置。无法修复时直接给五栏正文，不让学员承担技术排错。
- **“案例是真实客户吗／可以把我的客户资料放进去吗？”** 案例是教学虚构或改编，不能当真实客户证据；真实资料先匿名，再决定是否生成本地文件。来源说明见[cases.md](cases.md)。
